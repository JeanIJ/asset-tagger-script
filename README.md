# Asset Tagger Script

Code:You SecOps Python practice script that builds a simple asset risk report from user input.

## Description
Prompts for analyst name, department, hostname, criticality, and a 1–10 risk score, then prints a formatted Cyber Defense asset report with a timestamp.

## Technologies
- Python 3

## Usage
```bash
python3 asset_tagger.py
```
